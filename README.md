# CP-gym


Practice repo for competitive programming problems (VNOJ, USACO, CSES, Codeforces, etc...). Not every problem I've solved has code pushed here — some solutions live only on the judge's own site, refer to the `md` in the corresponding folders.

**Programming language:** `C++`


**Aim:** This repo is my attempt to fight against overreliance on AI - vibe coding.

**AI acknowledgement:** No AI was used to generate solutions, only used to generate counter-tests to verify the solution.

**Note:** USACO does not store users' solution code, and hence, this repo only includes my solution to interesting and demanding problems, personally.

## Structure

```
Cpp_code/
├── usaco/          # USACO solutions
├── cses/           # CSES solutions
├── codeforces/     # Codeforces solutions
└── templates/      # reusable algorithm snippets
```
