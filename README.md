# CP-gym
`C++` only.

Practice repo for competitive programming problems (VNOJ, USACO, CSES, Codeforces, etc...)

Not every problem I've solved has code pushed here — some solutions live only on the judge's own site.

**Note:** USACO does not store users' solution code, and hence, this repo only includes my solution to interesting and demanding problems, personally.

## Structure

```
Cpp_code/
├── USACOGUIDE/
├── CSES/
└── CODEFORCES/
```

## Templates

Reusable snippets (DSU, Fenwick tree, segment tree, sparse table, monotonic deque) live in `templates/`.
